# অসমীয়া ভাষা ২.১ — শিকিবলৈ সহায় (Tutorial)

এই গাইডত ভাষাটোৰ মূল কথাবোৰ উদাহৰণসহ দিয়া হৈছে। সম্পূৰ্ণ নিয়ম আৰু ব্যাকৰণ (grammar) [spec.md](spec.md)-ত আছে।

প্ৰতিটো উদাহৰণ এটা `.asb` ফাইলত save কৰি চলাওক:

```bash

```

C কম্পাইলাৰ নাই নেকি? WebAssembly হিচাপে Node.js-তে চলাওক — `node src/cli.js run --backend wasm মোৰ_প্ৰ'গ্ৰাম.asb` — বা playground-ত ▶ চলাওক টিপক।

## ১. প্ৰথম প্ৰ'গ্ৰাম

```asb
লিখা "নমস্কাৰ বিশ্ব!"
```

`লিখা`-এ মানবোৰ space দি লিখে আৰু শেষত নতুন শাৰী দিয়ে। সংখ্যা অসমীয়া অংকত ওলায়:

```asb
লিখা "যোগফল:", ২ + ৩        # যোগফল: ৫
দেখুওৱা "ক"                  # নতুন শাৰী নিদিয়াকৈ
দেখুওৱা "খ"
লিখা                          # ক খ
```

`#`-ৰ পিছৰ লেখা মন্তব্য (comment)।

## ২. চলক আৰু প্ৰকাৰ (variables and types)

প্ৰতিটো চলকৰ প্ৰকাৰ লিখিব লাগে। মান নিদিলে চলক শূন্যৰে আৰম্ভ হয়।

```asb
পূৰ্ণ বয়স = ২৮            # ৩২-বিট পূৰ্ণ সংখ্যা
পূ৬৪ জনসংখ্যা = ৩১২০৫৫৭৬   # ৬৪-বিট
দশমিক উচ্চতা = ১.৭৫
বুলিয়ান ছাত্ৰ = সত্য
বাক্য নাম = "অসম"
আখৰ বৰ্ণ = 'A'
স্থিৰ পূৰ্ণ সৰ্বোচ্চ = ১০০   # সলনি কৰিব নোৱাৰি
পূৰ্ণ গণক                  # ০
```

| প্ৰকাৰ | কি ৰাখে |
| --- | --- |
| `পূৰ্ণ`, `পূ৮`, `পূ১৬`, `পূ৩২`, `পূ৬৪` | চিহ্নযুক্ত পূৰ্ণ সংখ্যা |
| `ধ৮`, `ধ১৬`, `ধ৩২`, `ধ৬৪` | চিহ্নহীন (০ বা ধনাত্মক) পূৰ্ণ সংখ্যা |
| `দশমিক`, `দশমিক৩২` | দশমিক সংখ্যা |
| `বুলিয়ান` | `সত্য` বা `মিছা` |
| `আখৰ` | এটা বাইট (ASCII আখৰ) |
| `বাক্য` | লেখা (string) |

দশমিকক পূৰ্ণলৈ নিবলৈ `হিচাপে` লিখক:

```asb
দশমিক উষ্ণতা = ৩৬.৬
পূৰ্ণ গোটা = উষ্ণতা হিচাপে পূৰ্ণ    # ৩৬
লিখা ৭ / ২, ৭ হিচাপে দশমিক / ২      # ৩ ৩.৫
```

## ৪. চৰ্ত (conditions)

```asb
পূৰ্ণ নম্বৰ = ৮২
যদি নম্বৰ >= ৯০ থাকিলে
    লিখা "এ+"
নহলে যদি নম্বৰ >= ৭৫ থাকিলে
```

গোটেই `যদি … নহলে যদি … নহলে` এটা `শেষ`-ৰে বন্ধ হয়।

এটা মানৰ বহুতো সম্ভাৱনা থাকিলে `বাছক`:

```asb

বাছক দিন
    ক্ষেত্ৰ ১, ৭
        লিখা "সপ্তাহান্ত"
    ক্ষেত্ৰ ২, ৩, ৪, ৫, ৬
        লিখা "কামৰ দিন"
    অন্যথা
        লিখা "ভুল দিন"
শেষ
```

সৰু চৰ্তৰ বাবে `?:` — `লিখা x % ২ == ০ ? "যুগ্ম" : "অযুগ্ম"`

```asb

    শেষ
```

## ১৩. সাধাৰণ ভুল

| ভুল | শুদ্ধ |
| --- | --- |
| `লিখা "ফল: " + x` | `লিখা "ফল:", x` |
| `পূৰ্ণ i = ২.৫` | `পূৰ্ণ i = ২.৫ হিচাপে পূৰ্ণ` বা `দশমিক i = ২.৫` |

| `যদি a == "হয়" থাকিলে` (বাক্য) | `যদি তুলনা(a, "হয়") == ০ থাকিলে` |

## ১৪. তিনিটা back end

একেটা প্ৰ'গ্ৰাম তিনি ধৰণে চলাব পাৰি; ফল একেই:

```bash
node src/cli.js run prog.asb                     # C → gcc/clang (মূল)
node src/cli.js run --backend llvm prog.asb      # LLVM IR → clang
node src/cli.js run --backend wasm prog.asb      # WebAssembly → Node.js (C কম্পাইলাৰ নালাগে)
```

ভুল বিচাৰিবলৈ debugger ব্যৱহাৰ কৰক:

```bash
node src/cli.js build --backend llvm -g -O0 prog.asb
gdb ./prog          # (gdb) break কাজৰ_নাম   (gdb) run   (gdb) next   (gdb) print চলক
```

WebAssembly-ত সূচক ৪ বাইটৰ, গতিকে `আকাৰ(পূৰ্ণ*)` ৪ হয় (native-ত ৮)। খালি সূচক ব্যৱহাৰ কৰিলে বা শূন্যৰে হৰণ কৰিলে প্ৰ'গ্ৰামটো অসমীয়াত ভুল দেখুৱাই ৰয়।
